# Pinned Pup by YMD

Peta pin lokasi pup lengkap dengan tanggal dan jam, warna Pantone per tipe Skala Bristol, dashboard, dan riwayat.

**Pasang di iPhone:** buka https://malegiw.github.io/pinned-pup/ di Safari, lalu Share > Add to Home Screen > Open as Web App. Atau pasang otomatis lewat https://malegiw.github.io/pinned-pup/pinned-pup.mobileconfig

## Versi 2.0 (November 2026)
- Tampilan Liquid Glass (gaya iOS 26), latar Pantone Cloud Dancer (Color of the Year 2026)
- Timer pup live: mulai, lalu Selesai mengisi jam, durasi, dan lokasi otomatis
- Toilet terdekat: toilet umum, SPBU, masjid, mal dari OpenStreetMap, dengan rute jalan kaki
- Pemicu (kopi, pedas, begadang, dll.) dan fasilitas toilet (semprotan, tisu, sabun, bayar)
- Gut Score mingguan, insight otomatis, dan Pup Wrapped ala story yang bisa dibagikan jadi gambar
- Heatmap di peta, kalender di Riwayat, 12 lencana dengan confetti
- Kunci app dengan PIN dan Face ID (passkey), getaran halus, hapus dengan tombol Batalkan
- Tab Saya: tema terang/gelap, backup, pulihkan, ekspor CSV

Data tersimpan di HP (localStorage). Buat backup berkala dari tab Saya.

Peta © OpenStreetMap contributors. Pencarian tempat: Photon (komoot). Toilet terdekat: Overpass API. Data kelurahan: Kemendagri via paket `geografis`. Heatmap: Leaflet.heat.
