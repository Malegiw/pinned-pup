# Pinned Pup by YMD

Peta pin lokasi pup lengkap dengan tanggal dan jam, warna Pantone per tipe Skala Bristol, dashboard statistik, dan riwayat.

**Pasang di iPhone:** buka https://malegiw.github.io/pinned-pup/ di Safari → Share → Add to Home Screen → Open as Web App.

- Data tersimpan di HP (localStorage). Gunakan tombol Backup di tab Riwayat secara berkala.
- Peta © OpenStreetMap contributors. Pencarian tempat: Photon (komoot). Data wilayah kelurahan: Kemendagri via paket `geografis`.
